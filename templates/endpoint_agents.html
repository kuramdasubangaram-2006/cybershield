Connect a Windows device

The agent reads only the listed Windows event IDs. It does not execute commands, collect full event text, or allow remote control.

  1. Create a device token below and copy it. Keep it private.
  2. Download the PowerShell agent. Open PowerShell using Run as administrator.
  3. Run the commands below. When prompted, return here, click Copy token, then press Enter in PowerShell. Do not paste the token into chat.
  4. Leave the PowerShell window open while monitoring.
  5. Revoke the device here to stop it sending events. Stop the script on the device too.

Only event IDs 4624, 4625, 1102, 1116, 1117, 5156, and 5157 are allowed. If Windows firewall auditing is enabled, network events can include source/destination IPs, ports, protocol, and direction. Usernames and full event messages are not sent.

PowerShell commands

Download the agent first. These commands run the newest downloaded copy. Execution Policy change applies only to this PowerShell window.

cd "$env:USERPROFILE\Downloads"
Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass

If PowerShell asks for confirmation, type Y and press Enter. Then run:

$agentFile = Get-ChildItem "$env:USERPROFILE\Downloads\cybershield-windows-agent*.ps1" | Sort-Object LastWriteTime -Descending | Select-Object -First 1
& $agentFile.FullName

At the token prompt, click Copy token above, switch back to PowerShell, and press Enter. The script reads it from your clipboard.
